# API Reference

All routes require an Amazon Cognito access token in the `Authorization` header. The API Gateway HTTP API validates the JWT before invoking a handler. Requests with JSON bodies use `Content-Type: application/json`.

```http
Authorization: Bearer <cognito-access-token>
Accept: application/json
Content-Type: application/json
```

Use the `ApiBaseUrl` CloudFormation output as the base URL. Route paths below are relative to that output. The API is configured with CORS for the deployed CloudFront origin and the configured local `FrontendOrigin`.

## Product

| Method   | Path                    | Success                                              | Other responses                                                    |
| -------- | ----------------------- | ---------------------------------------------------- | ------------------------------------------------------------------ |
| `POST`   | `/products`             | `201`, `{ "product": ... }`, and a `Location` header | `400` invalid input, `409` duplicate product, `500` internal error |
| `GET`    | `/products`             | `200`, `{ "products": [...] }`                       | `500` internal error                                               |
| `GET`    | `/products/{productId}` | `200`, `{ "product": ... }`                          | `400` missing ID, `404` not found, `500` internal error            |
| `PUT`    | `/products/{productId}` | `200`, `{ "product": ... }`                          | `400` invalid input, `404` not found, `500` internal error         |
| `DELETE` | `/products/{productId}` | `204` with no body                                   | `400` missing ID, `404` not found, `500` internal error            |

Product creation and replacement accept all fields below. `productId`, `createdAt`, and `updatedAt` are generated by the service and must not be sent.

```json
{
  "name": "Classic Notebook",
  "category": "Stationery",
  "price": 4.99,
  "quantity": 120,
  "lowStockThreshold": 25
}
```

`name` and `category` are non-empty strings up to 100 characters. `price` is a non-negative finite number. `quantity` and `lowStockThreshold` are non-negative safe integers. Unknown fields are rejected. `PUT` replaces the product's editable fields.

Example response:

```json
{
  "product": {
    "productId": "generated-id",
    "name": "Classic Notebook",
    "category": "Stationery",
    "price": 4.99,
    "quantity": 120,
    "lowStockThreshold": 25,
    "createdAt": "2026-01-01T00:00:00.000Z",
    "updatedAt": "2026-01-01T00:00:00.000Z"
  }
}
```

## Sales

| Method | Path     | Success                  | Other responses                                                                              |
| ------ | -------- | ------------------------ | -------------------------------------------------------------------------------------------- |
| `POST` | `/sales` | `201`, `{ "sale": ... }` | `400` invalid input, `404` product not found, `409` insufficient stock, `500` internal error |

Request body:

```json
{
  "productId": "existing-product-id",
  "quantity": 2
}
```

`quantity` must be a positive safe integer. The handler reads the product price and submits one DynamoDB transaction that conditionally decrements inventory and writes the sale. A failed inventory condition returns `409`; neither part of the transaction is committed.

Successful response:

```json
{
  "sale": {
    "saleId": "generated-id",
    "productId": "existing-product-id",
    "quantity": 2,
    "unitPrice": 4.99,
    "totalAmount": 9.98,
    "soldAt": "2026-01-01T00:00:00.000Z"
  }
}
```

Error responses have the shape `{ "message": "..." }`. Internal errors return a generic message; diagnostic details are not sent to clients. Cognito authorization failures are handled by API Gateway. No list-sales route is currently implemented.
